What is an API?

An Application Programming Interface (API) is a set of rules and protocols that allows two software applications to communicate with each other. In this nutritional risk system, the client can request packaged food data and the server stores and processes it.

REST (Representational State Transfer) is an architectural style used to design networked applications. A RESTful API treats each food record as a resource and exposes it using a URL.

HTTP Methods and CRUD Operations

HTTP Method CRUD Operation Description
GET Read Retrieve one or more product records.
POST Create Create a new packaged food record.
PUT Update (full) Replace the complete record.
PATCH Update (partial) Modify selected fields such as sugar or risk level.
DELETE Delete Remove a product record.

Path Parameter vs Query Parameter

Path Parameter: GET /food-products/1

Query Parameter: GET /food-products?risk_level=High

REST and RESTful Architecture

  • Client-Server Architecture: The client and server work independently.
  • Statelessness: Each request contains all required information.
  • Uniform Interface: GET, POST, PUT, PATCH, DELETE are used consistently.
  • Resource-Based: Food products are addressed by a unique URL.
  • Representation: Resources are exchanged in JSON format.

JSON Representation

{ "id": "1", "food_name": "Cream Biscuits", "category": "Bakery", "sugar_g": 18, "sodium_mg": 450, "risk_level": "High" }

HTTP Status Codes

Code Meaning Typical Use

400 Bad Request Error Malformed request.
404 Not Found Error Resource not found.
500 Internal Server Error Error Server issue.

Tools Used

JSON Server: A lightweight Node.js tool that turns a JSON file into a mock REST API.

Postman: A tool used to create and test HTTP requests and inspect responses.

Introduction to React

React is an open-source JavaScript library used for building user interfaces for web applications. It follows a component-based architecture in which a large interface is divided into smaller, independent, and reusable components. A product catalogue application can be divided into components such as App, Header, FilterBar, ProductGrid, and ProductCard.

Functional components are the standard approach in modern React. A component is a JavaScript function that returns JSX, which describes what the interface should look like.

React Components and JSX

Example of a functional component:

function Header() { return ( <header> <h1>TechStore</h1> <p>Engineering Lead</p> </header> ); }

JSX rules include: one parent element, use of className instead of class, JavaScript expressions inside curly braces, and camelCase attributes such as onClick.

Component-Based Architecture

The product catalogue follows a modular structure:

App ├── Header ├── FilterBar └── ProductGrid └── ProductCard

This architecture demonstrates component composition, where smaller units are combined to form the complete application. It improves reusability, maintainability, readability, and scalability.

Static Data, Props, and List Rendering

In this experiment the application uses static data stored separately from the UI components. Product data is represented as JavaScript objects and passed to child components using props.

const products = [ { id: 1, name: "Wireless Headphones", category: "Electronics", price: 299.99, inStock: true }, { id: 2, name: "Gaming Keyboard", category: "Accessories", price: 129.5, inStock: true } ]; <ProductCard product={product} />

The JavaScript map() method is used to loop through the product array and render one card per item. The key attribute helps React identify each item efficiently.

Conditional Rendering and CSS Styling

React supports conditional rendering based on data values. For example, if a product is in stock, the button displays Add to Cart; otherwise the button shows Out of Stock.

{product.inStock ? ( <button>Add to Cart</button> ) : ( <button disabled>Out of Stock</button> )}

CSS is applied through class names to style the header, search controls, product card layout, ratings, prices, and stock status. This combination of React and CSS produces the final UI.
